A complete queued router system that:

1. Handles push notifications with 4 types:
   • cart (requires auth)
   • collection (requires auth)  
   • home (public)
   • announcement (public)

2. Smart routing logic:
   • If user is logged in → Navigate immediately
   • If user is NOT logged in → Queue the route
   • After login → Automatically navigate to queued destination

3. Persistent queue:
   • Routes saved to cache
   • Survives app restarts
   • Auto-cleared after navigation

SCENARIO 1: User Logged In + Cart Notification
  1. Notification arrives: type="cart"
  2. System checks: User is logged in ✓
  3. Navigate immediately to /cart

SCENARIO 2: User NOT Logged In + Collection Notification
  1. Notification arrives: type="collection"
  2. System checks: User NOT logged in ✗
  3. Route queued in cache
  4. User sees login page
  5. User logs in successfully
  6. processQueuedRoute() called automatically
  7. Navigate to /collection with collection details

SCENARIO 3: Announcement Notification
  1. Notification arrives: type="announcement"
  2. No auth check needed (public route)
  3. Navigate immediately to /home
